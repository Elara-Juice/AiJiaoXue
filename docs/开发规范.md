## 3. 枚举

- 全部枚举只在 `data/model/Enums.kt` 定义，任何模块不得自己写状态字符串或 Int 常量。
- 数据库存英文枚举名（如 `IN_PROGRESS`），界面显示 `label`（如“进行中”）。
- 已有枚举值不得改名或删除，只能追加。

| `Role` | ADMIN 教学管理人员 / SUPERVISOR 教学督导 / TEACHER 任课教师 |

## 4. 业务规则的唯一实现

以下计算只能调用 `Rules.kt`，不要在页面里重写：

- 总分：`EvalRules.totalScore(evaluation.scores())`，每维 1–5 分按权重换算百分制，四舍五入取整。
- 等级：`EvalRules.gradeOf(total)`。
- 任务编号：`TaskCode.of(supervisionDate, seq)`，格式 `DD` + 督导日期 + 三位当日序号，如 `DD20261003-001`。序号 = `taskDao.countByCodePrefix(TaskCode.prefixOf(date)) + 1`。
- 今天：`DateFormats.today()`。

任务状态只能由业务操作驱动（US06）：

| 操作 | 状态变化 | 负责模块 |
|---|---|---|
| 创建任务 | → NOT_STARTED | ui/course |
| 首次进入采集页 | NOT_STARTED → IN_PROGRESS，写 `classStartAt` | ui/capture |
| 结束课堂采集 | IN_PROGRESS → PENDING_EVALUATION，写 `classEndAt` | ui/capture |
| 提交评价 | PENDING_EVALUATION → COMPLETED | ui/evaluation |

## 5. 文件存储

- 统一通过 `FileStore` 创建和删除文件，不要自己拼路径。
- 目录：`filesDir/tasks/{taskId}/audio/`、`filesDir/tasks/{taskId}/photo/`。
- 文件名：`AUD_yyyyMMdd_HHmmss.m4a`、`IMG_yyyyMMdd_HHmmss.jpg`。
- 音频格式：m4a（AAC），满足 Sprint 2 转写要求。
- `Material.filePath` 只存相对路径，如 `tasks/12/photo/IMG_20261003_101530.jpg`。
- 删除材料：先 `FileStore.delete()`，再 `captureDao.deleteMaterial()`。

## 6. 页面与导航

- 路由只在 `navigation/Routes.kt` 定义，跳转用 `Routes.capture(taskId)` 这类函数，不要手写字符串。
- 模块之间只传 ID（`taskId`、`courseId`），不传对象；目标页面自己按 ID 查库。
- 每个页面进入时都要校验当前用户角色和数据归属，不能只靠首页不显示入口（F0 业务规则 2）。
- 列表数据用 DAO 返回的 `Flow`，在 ViewModel 里转成 `StateFlow`，页面用 `collectAsState()`。

## 8. Git

- 分支：`feature/<缩写>-<模块>`。缩写：李奕萱 `lyx`、王博田 `wbt`、于卓君 `yzj`、孙浩然 `shr`。例如 `feature/yzj-evaluation`。

- 一个提交只做一件事；提交信息里写上对应的 US 编号。
- 合并到 `main` 前先拉取最新 `main`，本地能编译、能运行到自己的页面再合并。

## 9. 数据库变更

- 改动任何实体后，把 `AppDatabase` 的 `version` 加 1，并在群里说明。

- `app/schemas/` 下的 JSON 由编译自动生成，需要一并提交。
