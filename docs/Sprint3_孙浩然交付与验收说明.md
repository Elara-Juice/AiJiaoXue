整理日期：2026-10-26。开发分支：`feature/shr-sprint3-governance`。起点：团队 `main b79aefb`，已包含于卓君、王博田、李奕萱的 Sprint 3 增量。

## 实现与入口

| 故事 | 用户入口与操作 | 数据来源与边界 |
|---|---|---|
| US37 可复用教学亮点 | 教师首页 → 教学亮点与互动策略 → 选择课堂 → 填写做法并保存；在另一课堂选定改进重点后复用 | 仅本人已提交反馈；督导亮点原文与教师做法分别保存，不更改正式评价 |
| US39 互动改进策略 | 同页选择改进重点 → 调整策略 → 采用 → 打开改进计划填写完成日期并确认 | 本地规则根据具体互动/参与问题匹配；教师自主选择；问题、候选原文、出处及当前措施可查；已确认计划不能改写 |
| US40 案例与资源 | 在匹配的问题下查看资源、出处和实施步骤，自主调整并加入计划 | 内置教学参考目录，保留原始来源网址；不调用网络模型、不自动证明教学效果。本次实现此原 Could 故事，不据此补写计划会决定 |
| US47 教师改进趋势 | 管理员首页 → 教学质量态势；教师首页 → 教学改进趋势 | 按教师、课程及日期筛选；只读取正式结果和冻结指标；同一教师同一课程至少两次有效课堂才比较；缺测和口径不一致给出原因 |
| US48 整体质量态势 | 管理员首页 → 教学质量态势 → 查看汇总和课堂来源 | 同时展示问题分布、已确认措施状态、实际实施记录及正式复评核验；去重统计；本地数据库范围，不代表跨设备或全校数据 |

策略/资源/亮点采用后作为教师确认新增的草稿措施进入现有计划，来源另表保存。教师仍需在计划页填写日期并确认；本模块不会自动确认计划、填写实施事实或给出“已改善”结论。重复点击采用返回已有措施，不覆盖教师修改。

## 与现有模块衔接

- 复用已提交评价、原问题、改进计划和措施；US43/44 的实际实施记录进入治理查询。
- US45 的正式 `MetricSnapshot` 提供趋势数据；US46 的人工核验提供复评态势。同一业务复评关联取最新核验，不把历史多次核验累计成多个已改善问题。
- 修复快照提前占位：评价提交前不允许生成正式指标快照；正式提交时再冻结。旧缺测快照不自动改写，也不补造历史指标。
- Room v7 → v8 仅新增 `teaching_highlights`、`teaching_adoptions`；保留 v1 起的升级路径、既有实体和原结果。
- 教师仅可处理本人数据；管理员可查看治理汇总；督导不因该模块获得全量教师信息。查询层执行角色和归属校验。
- 保存/采用尚未完成时阻止离页进入计划，避免另一个页面用旧措施列表覆盖新记录；页面恢复后重新读取重点、措施和确认状态。
- 全量回归发现原拍照模块可能因文件时间略早于开课时间而产生负偏移。本分支保留原拍摄时间，将课堂相对偏移下限限制为零，并新增确定性回归用例。

## 固定评估与复现数据

固定验证数据只在测试源集中建立，不写入用户正在使用的数据库。

| 验证集 | 覆盖 |
|---|---|
| `TeachingSupportCatalogTest` | 明确互动/参与问题的策略与资源匹配；非问题、无输入及证据不足时不生成诊断；出处与资源引用有效 |
| `TeachingSupportTest` | 亮点保存与跨课堂复用、策略编辑及来源、资源采纳、重复操作、角色/归属、草稿与已确认计划、正式快照提交门槛 |
| `TeachingSupportUiTest` | 真实 Room → ViewModel → 页面操作及重新读取 |
| 治理模块测试 | 两位教师/两门课程、同课程多次正式课堂、指标缺失/不可比、时间过滤、来源下钻、落实与复评分开、核验去重及权限 |
| 迁移与既有回归 | 旧库升级保留评价、确认计划、实施、复评和核验；S1/S2/S3原业务继续验证 |

演示前在独立测试环境使用既有演示账号：管理员 `admin`、督导 `sup01/sup02`、教师 `tea01/tea02`。账号初始密码沿用项目说明。勿清除真实使用数据来准备演示。

1. 为教师一的同一课程建立两次课堂；至少一次含互动或参与问题，按原流程提交评价。为教师二另一课程再准备一条正式评价。
2. 教师一在第一条反馈确定改进重点，保存教学亮点、调整策略并采用；在计划页补日期并确认。
3. 在“改进待办”进入实施记录，填写真实的测试步骤和附件；演示数据注明用于验证，不作为真实教学成效。
4. 督导以“跟踪复评”建立后续课堂关联，完成正式评价；按证据保存人工核验。只有测试用途时，核验说明明确为演示记录。
5. 教师查看本人趋势；管理员筛选教师/课程/日期，核对问题、措施落实与复评结果，并下钻来源。
6. 演示异常：切换其他教师不能读写原教师数据；未提交课堂不进入正式趋势；仅一次课堂、缺测或不同口径时不强行计算改善。
