# 开发环境搭建指南

适用Windows。本机已完成环境下载和命令行验证；新电脑按下表准备，工程版本以Gradle Wrapper和版本目录为准。

## 1. 必要准备

| 组件 | 本项目使用版本/位置 | 获取方式 |
|---|---|---|
| Git | 本机2.53.0，已安装 | 新电脑安装Git |
| Android Studio | Rabbit 1，2026.2.1.8；D:\Android\Android Studio | [官方下载](https://developer.android.com/studio) |
| Java | Studio自带JBR 25.0.3 | 无需另下JDK |
| Android SDK | API37.0、Build-Tools36.0.0、Platform-Tools；D:\Android\Sdk | Studio的SDK Manager |
| 模拟器 | AiJiaoXue_API37，Google APIs x86_64镜像 | SDK Manager和Device Manager |
| Gradle及项目依赖 | Wrapper固定9.6.0；缓存D:\Android\.gradle | 首次构建自动下载 |

建议在D盘为IDE、SDK、模拟器与缓存预留约30GB。本项目不需要服务器、数据库服务或AI SDK。真机准备Android 10及以上、支持APK安装的设备和可传输数据的USB线。

## 2. 本机直接使用

源码目录：`D:\大三上\软件项目管理\实验\2\yzj-sprint1`。英文入口 `R:\` 映射到同一目录，用于避免Android工具的中文路径问题。

在PowerShell加载现有环境：

```powershell
. 'D:\Android\tools\Enter-AiJiaoXue.ps1'
```

脚本设置JBR、SDK、AVD和Gradle缓存并进入工程。Android Studio打开 `R:\`，Gradle JDK选自带JBR。

本机模拟器使用host GPU、4GB内存和4核；软件渲染曾出现启动器无响应：

```powershell
& "$env:ANDROID_HOME\emulator\emulator.exe" -avd AiJiaoXue_API37 -gpu host -memory 4096 -cores 4 -no-snapshot-load
```

在另一个已加载环境的PowerShell中构建和测试：

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug --offline
.\gradlew.bat :app:connectedDebugAndroidTest --offline
```

新电脑首次构建去掉 `--offline`，先下载依赖。设备测试需要已启动的模拟器或已授权USB调试的手机。


## 4. 常见问题

- 路径或Gradle Worker报错：使用英文映射和 `D:\Android\.gradle` 缓存；不要复制出另一套源码。
- JDK不匹配：Gradle使用Studio自带JBR；无需改动其他课程的全局Java配置。
- 下载失败：检查网络和Studio代理设置；离线构建需已有完整缓存。
- 设备无法连接：检查USB调试授权、数据线及厂商驱动。真机验收仍待用户准备设备。
- 不提交本机的local.properties、缓存、build目录或APK；GitHub写权限在推送前验证。
