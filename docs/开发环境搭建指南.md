# 开发环境搭建指南（Windows）

全组统一版本：Android Studio Rabbit 1（以 Help → About 显示为准，四人保持一致），SDK API 37，minSdk 29。
全部装完约 1–2 小时，主要是下载时间。

## 0. 避开中文路径

Windows 用户名是中文时，模拟器和 Gradle 容易报错，提前设置：

1. 新建文件夹 `D:\Android`。
2. 设置 → 系统 → 系统信息 → 高级系统设置 → 环境变量，在“用户变量”中新建：
   - `ANDROID_AVD_HOME` = `D:\Android\avd`
   - `GRADLE_USER_HOME` = `D:\Android\.gradle`
3. 项目代码放在纯英文路径下，例如 `D:\Android\project`。

## 1. 下载与安装 Android Studio

1. 下载地址：https://developer.android.google.cn/studio （国内镜像）。
2. 运行安装包，保持勾选 Android Virtual Device，安装路径可改为 `D:\Android\Android Studio`。
3. 首次启动的 Setup Wizard 选 **Custom**，SDK 位置改为 `D:\Android\Sdk`，接受全部 License。
4. 不需要单独装 JDK，Android Studio 自带 JBR。
5. 电脑建议 16GB 内存（8GB 能用但模拟器较卡），磁盘预留 20GB。

### HTTP Proxy 设置

| 情况 | 选择 |
|---|---|
| 没开 VPN / 代理软件 | No proxy（默认推荐） |
| 开着 Clash、V2Ray 等 | Manual：HTTP，Host `127.0.0.1`，Port 按软件显示（Clash 常为 7890，V2Ray 常为 10809） |
| 学校网络要求 PAC | Auto-detect（一般用不到） |

之后可在 File → Settings → Appearance & Behavior → System Settings → HTTP Proxy 修改。
打开项目时若弹窗询问是否把代理同步给 Gradle：代理软件会一直开着才点同意，否则点 No。

## 2. 安装 SDK

More Actions（或 Tools）→ SDK Manager：

- SDK Platforms：勾选 Android 17.0（API 37）。若标注 Preview / Beta，改选下面最新的正式版本。
- SDK Tools：确认勾选 Build-Tools、Platform-Tools、Android Emulator；AMD 处理器加勾 Android Emulator Hypervisor Driver。

说明：SDK 版本只决定用什么编译（compileSdk），APK 能装在哪些手机由 minSdk 决定。项目 minSdk = 29，Android 10 及以上都能装。

## 3. 开启虚拟化

1. 搜索“启用或关闭 Windows 功能”，勾选“Windows 虚拟机监控程序平台”，重启。
2. 若模拟器仍提示未开虚拟化，进 BIOS 打开 Intel VT-x / AMD SVM。

## 4. 创建模拟器

Virtual Device Manager → + → Pixel 6 → 系统镜像选 API 37 的 x86_64 Google APIs → Finish → ▶ 启动。
如果 API 37 镜像很卡，可换 API 34 或 35 镜像，不影响项目编译。

## 5. 获取项目代码

1. 把 Gitee / GitHub 账号发给李奕萱，接受仓库邀请。
2. Android Studio → File → New → Project from Version Control，填仓库地址，目录选英文路径。
3. 等 Gradle 同步完成（首次 10–30 分钟），点 ▶ 在模拟器上运行。

## 6. 连接真机

### 普通安卓手机

设置 → 关于手机 → 连点“版本号” 7 次 → 开发者选项中打开“USB 调试”（小米 / OPPO / vivo 还需打开“USB 安装”）→ 连数据线并在手机上点“允许”。

### 华为手机

先看 设置 → 关于手机 → HarmonyOS 版本：

| 系统版本 | 运行 APK | 调试开发 |
|---|---|---|
| HarmonyOS 2 / 3 / 4 | 可以 | 可以 |
| HarmonyOS 5 及以上（纯血鸿蒙） | 不能 | 不能，改用模拟器，真机演示需另借安卓手机 |

HarmonyOS 2–4 的连接步骤：

1. 连点“版本号” 7 次开启开发者模式。
2. 设置 → 系统和更新 → 开发人员选项：打开“USB 调试”和“仅充电模式下允许 ADB 调试”。
3. 连线后 USB 方式选“传输文件”，手机上允许调试。
4. 仍识别不到就安装华为手机助手（HiSuite）获取驱动。

本项目不依赖 Google 服务，华为手机没有 GMS 不影响使用。

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| Gradle 同步卡住或 timeout | 重试；检查 HTTP Proxy；仍不行可配置阿里云镜像 |
| 模拟器黑屏或很卡 | 内存不足或虚拟化未开，可改用真机 |
| 报错里出现乱码路径 | 中文路径导致，检查第 0 步 |
| 构建报 JDK 错误 | Settings → Build Tools → Gradle，Gradle JDK 选自带 jbr |
| 识别不到手机 | 换能传数据的线；装手机品牌 USB 驱动 |
