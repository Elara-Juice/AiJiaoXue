# Sprint 3 王博田高级分析验收说明

## US18 口头禅与重复表达

- **输入**：当前任务实际采集的 `Material.note` 和 `InteractionEvent.note`；跳过空白文本及无有效时间位置的记录。不使用固定示例或预置课堂文本。
- **规则**：在 note 的连续字母/数字文字片段中枚举 2–8 个字符的连续片段，至少出现 2 次才计为重复表达；优先选较长且不重叠的命中，最多呈现 5 个表达。该规则只识别文本重复，不声称完成语音转写或识别所有口头禅。
- **输出**：命中时展示表达及规则命中次数；有有效文本但无命中时明确说明未发现规则命中的重复表达；无有效文本时返回“输入不足/无法分析”。
- **证据**：每个命中关联实际材料或互动事件 ID、课堂 `offsetMs`，并在证据说明中保留 note 内字符位置。未命中时引用实际参与统计的 note 来源和时间位置。
- **输入不足**：没有至少包含 2 个连续有效字符的真实 note 时，不生成表达结论，返回输入不足且不附伪造证据。

## US21 教学环节衔接

- **输入**：当前任务实际采集的材料及互动事件类型、记录 ID 和非负课堂 `offsetMs`。
- **规则**：按课堂时间位置分组，将相邻的不同时间点作为待检查区间；比较两端来源类别，类别变化标记为“记录类型切换线索”，类别相同标记为“同类记录延续线索”。该判断仅针对采集记录，不代表实际教学阶段变化或衔接质量；现有 BOPPPS 材料结论也说明材料本身不足以确认完整结构。
- **输出**：展示诊断方法、每个相邻记录时间区间、区间两端的类型和来源依据，并明确需人工审核；分析结果的 `startMs` / `endMs` 覆盖实际区间。
- **证据**：每个区间的起点、终点分别关联原材料或互动事件 ID，并记录对应的课堂时间位置；不生成虚构课堂节点。
- **输入不足**：没有时间记录时提示缺少有效时间位置；只有一个不同时间点时引用该真实记录并提示至少需要两个不同时间点；两种情况均不伪造衔接区间或完整课堂结构。

## 证据与人工审核流程

US18、US21 使用既有 `AIAnalyzer` / `AIResult` 输出，由 `AIAnalysisRepository` 按原有流程保存为 `AiAnalysisResult` 和 `AiEvidence`。分析页继续通过既有证据面板显示来源与时间，督导可从同一结果进入人工审核，沿用 `AiCorrection` 保存原文、修正内容、接受状态和审核时间；本轮未增加数据库实体或另建审核流程。
