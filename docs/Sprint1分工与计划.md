## 1. 技术方案

| 项 | 选择 |
|---|---|
| 平台 | 原生 Android，交付 APK |
| 语言 / UI | Kotlin + Jetpack Compose |
| 数据存储 | 手机本地 Room 数据库，Sprint 1 不做后端 |
| 包名 | `edu.neu.aijiaoxue` |
| minSdk / targetSdk | 29（Android 10）/ 37 |
| 工程目录 | `D:\Android\project\Aijiaoxue` |

不做后端的原因：5 天工期内省掉服务器部署、接口联调和网络鉴权。代价是三个角色只能在同一台手机上切换账号演示，不能跨手机同步，需在 Review 时说明，后续 Sprint 再评估是否加后端。

- US12 是 Must，和录音、拍照在同一采集页，由李奕萱统一完成。

## 4. Git 协作规范

- 仓库：Gitee 或 GitHub，名称 `AiJiaoXue`，由李奕萱创建并邀请组员。
- 分支：`main` 保持可运行；每人在 `feature/<姓名拼音>-<模块>` 分支开发，例如 `feature/wbt-course`。
- 合并：自测通过后合并到 `main`，合并前在群里说一声；合并后其他人及时拉取。
- 不提交 `local.properties`、`build/`、`.gradle/`（项目自带 `.gitignore` 已排除）。
