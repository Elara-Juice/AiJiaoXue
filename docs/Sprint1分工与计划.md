## 3. 代码包结构

路径相对 `app/src/main/java/edu/neu/aijiaoxue/`。

| 目录 | 内容 |
|---|---|
| `data/`、`navigation/`、`ui/login/` | 公共数据、路由与登录 |
| `ui/course/`、`ui/arrange/`、`ui/feedback/` | 课程、安排、进度、教师反馈 |
| `ui/capture/`、`ui/engagement/` | 课堂采集、互动与参与状态 |
| `ui/evaluation/`、`ui/improve/` | 评价历史及教师改进 |

模块之间通过taskId/courseId交接，使用已有Routes、Enums和Rules；公共文件变更须协调，保留已有接口签名。

## 4. 协作与联调

仓库为 https://github.com/Elara-Juice/AiJiaoXue 。于卓君使用已创建的 `yzj-sprint1` 分支；其他成员按团队约定开发。自测和人工审查完成后再提交，main的合并由DRI协调。

| 衔接 | 输入/输出 |
|---|---|
| 采集 → 评价 | 任务置为PENDING_EVALUATION，跳转Routes.evaluation(taskId) |
| 评价 → 历史/反馈 | 提交后评价SUBMITTED、任务COMPLETED、关联安排DONE |
| 反馈 → 改进重点 | 本人课程已提交反馈，跳转Routes.improveFocus(taskId) |
| 重点 → 计划 → 待办 | 保存重点、确认措施和日期后生成待办；保留问题、计划和任务关联 |

改进建议沿用督导填写的综合建议，由教师按事项采纳或编辑；没有建议时可自行新增。确认后的计划内容和日期锁定，执行状态可在待办中更新。
